# Product Information System

Product Information System adalah aplikasi sederhana berbasis PHP yang digunakan untuk menampilkan dan mengolah informasi produk.

## Tujuan

Project ini dibuat untuk menerapkan konsep dasar pemrograman PHP, yaitu:

- Array
- Multidimensional Array
- Function
- Perulangan `foreach`
- `require_once`
- HTML
- CSS
- Pemisahan Data Layer, Processing Layer, dan Presentation Layer

## Teknologi yang Digunakan

- PHP
- HTML
- CSS
- XAMPP
- Apache
- Git
- GitHub
- Visual Studio Code
